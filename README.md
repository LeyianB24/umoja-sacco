# Umoja Sacco Management System (USMS)

A comprehensive cooperative management and fintech platform empowering drivers, fleet operators, and transport professionals across Kenya with high-yield savings, low-interest loans, welfare protection, and automated M-Pesa transactions.

---

## 🏛️ System Architecture

- **Frontend**: Next.js (App Router), TypeScript, Modern Vanilla CSS Design Tokens (Dark Theme / High Contrast Fintech Palette).
- **Backend API**: PHP REST APIs with MySQL / MariaDB database engine.
- **Payment Gateway**: Integrated Safaricom Daraja M-Pesa API for real-time STK Push and C2B payment processing.
- **Reporting & Compliance**: Financial auditing, automated trial balances, SASRA compliance reports, and export tools.

---

## 🚀 Getting Started

### 1. Backend Setup
- Ensure Apache/PHP and MySQL are running via XAMPP.
- Configure backend database connection parameters in `backend/config/database.php`.

### 2. Frontend Setup
Navigate to the frontend directory and launch the development server:
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to access the application.
