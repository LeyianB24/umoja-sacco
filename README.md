# Umoja Sacco Management System (USMS)

A comprehensive cooperative management and fintech platform empowering drivers, fleet operators, and transport professionals across Kenya with high-yield savings, low-interest loans, welfare protection, and automated M-Pesa transactions.

---

## 🏛️ System Architecture

- **Application**: Next.js 14 (App Router), TypeScript, Prisma ORM, Modern Vanilla CSS Tokens (Dark Mode / High Contrast Fintech Palette).
- **Database**: Serverless PostgreSQL (Neon Database).
- **Payment Gateway**: Safaricom Daraja M-Pesa STK Push & C2B transaction processing.
- **Automation**: Native TypeScript Cron Job engine (fines, reminders, ledger reconciliation, dividends).
- **Reporting & Compliance**: Financial auditing, automated trial balances, SASRA compliance reports, and export tools.

---

## 🚀 Getting Started

Navigate to the `umoja-sacco` directory and launch the development server:

```bash
cd umoja-sacco
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to access the application.
